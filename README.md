# Voicebots Centauro · HappyRobot

Documentación, histórico de decisiones, prompts versionados y rutinas de análisis de los
voicebots de Centauro Rent a Car en HappyRobot (Minibús ES, IT y PT; Prolongaciones).

- Empieza por **`CLAUDE.md`**: contexto, estructura y forma de trabajar.
- **¿Por qué está así?** → `docs/decisiones.md`
- **¿Qué falta?** → `docs/pendientes.md`
- **¿Cómo va?** → `docs/informes/` y el artefacto de Minibús

## Trabajar con Claude Code
1. Clona el repo y ábrelo con Claude Code (terminal, escritorio o claude.ai/code).
2. Conecta en tu cuenta los conectores de HappyRobot y RingCentral.
3. Claude lee `CLAUDE.md` al empezar. Pide confirmación antes de cambiar nada en HappyRobot.
